# 實驗與腳本歸檔引導

## 目的

把本次工作產出的程式碼與腳本檔案（實驗程式、ad-hoc 腳本、可重現樣本）歸檔到當日 `scripts/` 目錄。

## 歸檔位置

```
<project>/chat_with_my_agent/{yyyy}_{mm}_{dd}/scripts/{folder_name}/
```

- `folder_name`：kebab-case，全小寫，依歸檔的程式主題命名
- 直接寫到目標路徑；上層資料夾若不存在，先建立再寫入

## 歸檔什麼

- 新寫／大改的腳本與實驗程式
- 重現所需的附帶檔案：設定檔、抓資料腳本、環境依賴說明
- 不歸檔：一時的單行指令（記在主日誌 How 章節即可）

## 歸檔要求

- 保留原始檔案結構，把能跑起來所需的檔案原樣放進來
- 歸檔根部放一份 `README.md`：做什麼、怎麼跑、依賴、執行順序
- 歸檔後，主日誌 `References` 連結到歸檔根部（直達 README 最好）

## 與專案源碼的邊界

專案源碼保持在原位置，不需要歸檔；只歸檔實驗、ad-hoc 腳本這類**不在專案源碼樹內**的東西。
