# 參考文件歸檔指引

## 目的

把本次工作用到的參考材料與產出的檔案歸檔到當日 `assets/` 目錄。

## 歸檔位置

```
<project>/chat_with_my_agent/{yyyy}_{mm}_{dd}/assets/{folder_name}/
```

- `folder_name`：kebab-case，全小寫，依歸檔的材料主題命名
- 先建立完整路徑的資料夾，再寫入檔案（寫入不會自動建立上層資料夾）

## 歸檔什麼

- 外部參考材料：網頁快照、引述摘錄、規格／標準文件副本
- 產出的檔案：報告、圖表、匯出的資料檔
- 一個主題一個 `folder_name`；檔案多時在根部加 `README.md` 列出各檔案來源與用途

## 歸檔要求

- 保留原始檔名與格式，不要修改內容
- 歸檔後，主日誌 `References` 連結到**具體檔案**，不只連結目錄
