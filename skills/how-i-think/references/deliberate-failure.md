# 刻意失敗法（Deliberate Failure Method）

## 核心心法

實驗不只產出「成功」。**必要的失敗也是一種路線，而且可以被刻意選取。**

- **往目標邁進，同時開啟路線**：不鎖死一條路。朝目標推進的同時，持續探索各種路線與可能性。
- **失敗可以被刻意觸發**：有時最佳下一步是一場必定會失敗的實驗——用最小成本排除大部分不確定性。
- **排除本身就是資訊**：刻意且覆蓋範圍廣泛的註定失敗，其驗證作用的資訊本身就是前進路上巨大的助益。知道「哪條路走不通」跟知道「哪條路走得通」一樣珍貴。
- **資訊換成本決定位次**：單位成本能排除最多不確定性的路線，優先做——即使它註定失敗。

## 什麼時候做「註定失敗實驗」

| 訊號 | 動作 |
|------|------|
| 多條路線並存、最大不確定性不明 | 設計一場最小成本的註定失敗，先把最大的不確定性炸開 |
| 失敗代價小、資訊價值大 | 直接做，不猶豫 |
| 失敗代價大 | 換小規模、廣覆蓋的替代實驗，保住核心資源 |
| 失敗也學不到東西 | 不做。沒換到資訊的失敗是事故，不是工具 |

## 操作步驟

1. **列不確定性**：目標路上有哪些未知會卡住推進？
2. **挑最大的**：排除哪個之後，剩下的路線最乾淨？
3. **設計最小註定失敗**：用最小成本觸發它。刻意、廣覆蓋、一次掃掉一大片。
4. **收資訊、重排路線**：把「走不通的」標進排除清單，沿著剩下的路線繼續推進。

## 應用時機

| 情境 | 動作 |
|------|------|
| 面對多路線決策 | 先問：能不能用一場最便宜的註定失敗，排除最多的不確定性？ |
| 使用者說「不知道選哪條」 | 給排除式路線：列出不確定性清單，建議先做一場最小註定失敗 |
| 實驗失敗後 | 不當成挫折。先問：換到什麼資訊了？值不值得？ |

## 跟開路思維的關係

開路思維在乎「出路大於困境」。刻意失敗是開路工具：主動製造一個小困境，把它壓縮成一份排除清單，讓剩下的路更短。

## 提醒

- **刻意不等於自毀**：註定失敗必須有明確要排除的假說。沒有假說可排除，失敗只是事故。
- **覆蓋範圍優於深度**：一場廣覆蓋的註定失敗，資訊價值通常大過數場窄覆蓋的僥倖成功。
- **排除清單要寫下來**：排除結果是資產。下一場實驗直接跳過已排除的路線。

---

> 實驗不只為了找到走得通的路。
> 刻意觸發失敗、排除不確定性，也是往目標推進。
> **排除掉的，也是路。**
