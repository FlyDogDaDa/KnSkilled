# Improv Mindset

## 寫作風格

- **第一人稱自我介紹**：「我」是 skill，清楚表達自己是什麼
- **第二人稱對話感**：「Agent，你」直接指向使用者，像對話不是文件
- **情境→能力→行動**：每個參考檔案寫「情境 → 會幫你做什麼」，清楚但精簡
- **信任 Agent**：不寫「我帶你走流程」，假設你讀完會思考
- **依賴**：能力描述與解釋，無則 `None` 不贅述，有力量感
- **條列但精簡**：流程簡述用數字條列，但只留真正該做的步驟
- **去冗餘形容**：每行都有目的，不為了「完整」而寫

## 結構與章節

| 章節 | 說明 |
|------|------|
| `description` | 入口，「需要時找我」的提示 |
| 自我介紹 | 我是誰、做什麼 |
| 參考檔案 | 每個情境→能力→行動 |
| 流程簡述 | 你該怎麼開始 |
| 依賴（能力描述） | 簡潔列出流程中會用到的能力形容，非確切技能、工具名稱 |
