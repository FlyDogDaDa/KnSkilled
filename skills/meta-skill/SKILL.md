# Meta Skill

Meta Skill 管理專案裡所有 skills。每個 skill 宣告自己的 dependencies，由各功能的參考檔案帶路。

## 參考檔案

每個參考檔案各自掌握一項能力。Agent，需要時直接讀取，我會帶你走流程。

- `references/master.md` — 要使用某個技能時，帶你確認 deps 並執行
- `references/update.md` — 要更新技能時，帶你追蹤狀態變化
- `references/improv_mindset.md` — 要精進技能時，帶你思考更新方向

## 流程簡述

1. 讀完我後，思考你的動機 — 要使用、更新、還是精進？
2. 從 meta-skill 參考檔案讀你要的技能
