# Minerva HCs（Habits of Cognition）第一手來源調查

> 整理日期：2026-08-25
> 目的：蒐集官方/第一手素材，供後續訂製自訂 agent 技能包使用。

## 關鍵結論

1. **官方 HC 數量會隨年份調整**（官方明言 "The set of HCs is adjusted each year"）：
   - 官方教材 PDF（Kosslyn）：「more than 100」
   - MIT Press 2017 書 Appendix A 轉錄：約 109 個
   - 2019 學生（Medium）：「over 120」
   - 2024 官方文件：「approximately 115」
   - ⚠️ **mnv-thinking-skill 的「76 個」與任何官方數字都對不上，是該技能包的二手整理**。訂製技能包時不要把它當官方基準。
2. **官方框架（四核心能力，所有來源一致）**：
   - I. Thinking Critically：A. Evaluating Claims / B. Analyzing Inferences / C. Weighing Decisions / D. Analyzing Problems
   - II. Thinking Creatively：A. Facilitating Discovery / B. Solving Problems / C. Creating Products, Processes & Services
   - III. Communicating Effectively：A. Using Language / B. Using Nonverbal Communication
   - IV. Interacting Effectively：A. Negotiating, Mediating & Persuading / B. Working with Others / C. Ethical Problems & Social Consciousness
3. 每個 HC 有 **hashtag 名稱**（如 `#estimation`、`#rightproblem`）、**H/C 分類**（Habit = 認知技能；Concept = 基礎知識）、**5 點 rubric**（1=未理解，5=深度理解並創新應用），且每年由師長與雇主回饋調整。

## 對訂製技能包的建議（素材層面）

- **骨架**：用官方四核心能力分類（上面第 2 點），別照搬 76 個清單的分類。
- **內容**：每個 HC 至少需要——hashtag、一句定義（官方 PDF 有 11 個現成範例格式：定義段＋Application example）、H/C 類型。
- **rubric**：官方每個 HC 配 1–5 點 mastery rubric；技能包可把它轉成 self-check 清單。
- **精簡選項**：hahao 26 HC 子集是現成的「最小可用集」，適合先做技能包 v1。
